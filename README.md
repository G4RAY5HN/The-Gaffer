# The Gaffer ⚽

**Your football companion — training sessions, a notes journal, coaching tips, and a streak tracker, all in one installable app.**

🔗 **Live app:** https://g4ray5hn.github.io/The-Gaffer/

Built for a right-footed, any-flank winger with a set-piece weapon — but useful for any outfield player rebuilding their game.

---

## Features

- **📋 Sessions** — Weekend training plans: a Saturday "Full Rebuild" (~4 hr) and a Sunday "Sharpener" (~2 hr), broken into expandable phases with rests built in.
- **📝 Notes** — A journal for goals, free kicks, match notes, and personal bests. Saves automatically on your device.
- **💡 Tips** — A coaching library covering free kicks, skill moves, shooting, passing, defending, and positioning — with tips tailored to your game highlighted.
- **📅 Tracker** — A 28-day streak grid with current streak, best streak, and total sessions.

## Install it

The Gaffer is a Progressive Web App (PWA), so it installs like a native app and works offline.

- **Desktop (Chrome/Edge):** Open the live link, then click **Install as App** on the page or the install icon in the address bar.
- **Android (Chrome):** Open the link → menu → **Add to Home screen / Install app**.
- **iPhone (Safari):** Open the link → **Share** → **Add to Home Screen**.

Once installed, it runs in its own window and keeps working with no internet.

## Notes on your data

Your notes, streak, and tracker progress are saved locally on **your** device — they aren't uploaded anywhere and aren't shared between devices.

## Built with

Plain HTML, CSS, and JavaScript — no frameworks. Hosted free on GitHub Pages.
