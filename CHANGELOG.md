# Changelog

All notable changes to The Gaffer are listed here.

## Version 1.2
- **Session Builder** — set how long you have with a slider (15 min to 4 hours) and the app builds a full session to fit
- Pick **what to work on** — touch, shooting, passing, defending, goalkeeping, physicality — single, multiple, or balanced
- Tell it **what kit you have** (ball + wall assumed; add cones, goal, rebounder, partner, or agility ladder) and it only picks drills you can actually do
- Big **drill library** (~60 drills) tagged by focus area and equipment, so sessions stay varied
- **Smart scaling** — warm-up and cool-down have sensible minimums, rests scale with length, main work absorbs the rest
- **Warm-up scales 5 to 15 minutes** with session length and now uses your kit (cones and ladder get real use)
- **Targeted cool-down stretches** that change based on what you trained
- Removed the old Saturday/Sunday preset naming
- **Notes overhaul** — expanded, colour-coded entry types (open-play goal, penalty, free-kick goal, assist, save, tackle, block, clearance, interception, skill move, nutmeg, dribble past, match note, PB, note)
- Notes now show an **auto-tally** of your logged moments up top
- **Edit notes** as well as ability to delete
- Timer now runs the session you build, with lock-screen catch-up and phase-change notifications that don't interfere with music

## Version 1.1
- Added a guided session timer to track training sessions
- Timer auto-advances through each phase with a beep and vibration at every change
- Added play/pause, skip, and back controls, plus a progress bar and "up next" line
- Rest phases are flagged separately so you know when to breathe
- Timer stays accurate even if the screen sleeps mid-session
- Added the new app icon
- Improved caching so updates show up reliably

## Version 1.0
- Weekend training sessions: Saturday "Full Rebuild" and Sunday "Sharpener"
- Notes journal for goals, free kicks, match notes, and personal bests
- Tips library with coaching for every area, tailored to your game
- 28-day streak tracker with current streak, best streak, and total sessions
- Installable as an app, works offline
